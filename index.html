learning Git

This is my first Git repository. I am learning how to use Git for version control.

Git is a distributed version control system that allows multiple people to work on a project simultaneously without interfering with each other's work.

In this repository, I will be practicing basic Git commands such as:-

  • git init - Initialize a new Git repository
  • git add - Stage changes for commit
  • git commit - Commit staged changes to the repository
  • git push - Push local commits to a remote repository

Feel free to explore the repository and contribute if you like!

Happy coding!
